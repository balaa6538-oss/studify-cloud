# Studify Cloud — لوحة التحكم السحابية المركزية (SaaS Master Dashboard)

## نبذة عامة (Overview)
هذا المشروع المستقل يمثل **لوحة التحكم المركزية السحابية** الخاصة بمدير ومالك منصة **Studify** (المهندس بدر علاء). من خلال هذه اللوحة، يتم إدارة تراخيص واشتراكات مراكز التعليم (السناتر) المشتركة في النظام.

---

## المعمارية والربط بين النظامين (Architecture & Ecosystem)

يتكون نظام **Studify SaaS** من مشروعين مستقلين تماماً في الكود والمستودعات، ويرتبطان فقط من خلال قاعدة بيانات **Supabase** المركزية:

```text
┌────────────────────────────────────────────────────────┐
│  1. لوحة تحكم المالك (Studify Cloud)                   │
│  - المسار المحلي: Desktop\Studify-Cloud\index.html     │
│  - المستودع: github.com/balaa6538-oss/studify-cloud     │
│  - الوظيفة: إيقاف / تفعيل الاشتراك وتحديد الباقات       │
└──────────────────────────┬─────────────────────────────┘
                           │ يكتب (Update)
                           ▼
     ┌──────────────────────────────────────────────┐
     │           Supabase Central Cloud             │
     │  - جدول: settings (id: 1)                    │
     │  - حقل: config.subscription (JSONB)          │
     └─────────────────────┬────────────────────────┘
                           │ يقرأ لحظياً (Realtime Listen)
                           ▼
┌────────────────────────────────────────────────────────┐
│  2. نظام إدارة السنتر (Studify Center System)          │
│  - المسار المحلي: D:\Students                          │
│  - المستودع: github.com/Studify-Edu/studify-system      │
│  - الوظيفة: تشغيل السنتر، الحضور، الحسابات، الطلاب    │
│  - استجابة القفل: شاشة وهمية فورية عند التعليق/الانتهاء │
│  - قيود الباقة: حد أقصى للطلاب (600 / 750 / 1000)      │
└────────────────────────────────────────────────────────┘
```

## تفاصيل بنية البيانات في Supabase (Data Contract)
يتم تخزين بيانات الترخيص داخل جدول `settings` في الصف رقم `1` تحت كائن `config.subscription`:

| الحقل (Field) | النوع (Type) | الوصف (Description) |
|---|---|---|
| `is_active` | `boolean` | `true` = السيستم شغال، `false` = السيستم موقوف فوراً وتظهر شاشة القفل |
| `plan_key` | `string` | مفتاح الباقة: `monthly` (مرنة) أو `quarterly` (مريحة) أو `semi_annual` (ذهبية) أو `custom` |
| `plan_name` | `string` | اسم الباقة المعروض (مثل: الخطة المرنة، الخطة الذهبية) |
| `plan_start_date` | `string (YYYY-MM-DD)` | تاريخ بداية الاشتراك |
| `plan_end_date` | `string (YYYY-MM-DD)` | تاريخ انتهاء الاشتراك |
| `max_students` | `number` | الحد الأقصى للطلاب المسموح بتسجيلهم (600 / 750 / 1000) |
| `max_assistants` | `number` | الحد الأقصى لحسابات المساعدين (2 / 4 / 5) |
| `marketing_enabled` | `boolean` | تفعيل ميزة حملات الواتساب (مفعلة حصرياً في الخطة الذهبية) |
| `updated_at` | `string (ISO)` | تاريخ وتوقيت آخر تحديث |

## كيف يستجيب السيستم الأساسي (System Response)?
1. **في حالة الإيقاف (`is_active: false` أو انتهاء التاريخ):**
   - تنطلق شاشة قفل فورية (`#subscriptionLockScreen` و `#assistantSubscriptionLockScreen`).
   - يتم حجب لوحة التحكم وتظهر رسالة رسمية بضرورة سداد الاشتراك للتفعيل والتواصل مع الإدارة.
2. **في حالة التفعيل (`is_active: true`):**
   - تفتح اللوحة فوراً ويتمكن المركز من العمل بكامل الصلاحيات.
   - يتم التحقق من سعة الطلاب: إذا حاول المركز إضافة طالب يتجاوز `max_students`، يرفض السيستم الإضافة مع تنبيه رسمي بالترقية.

## تعليمات لأي مساعد ذكاء اصطناعي (AI Instructions)
- هذا المشروع مستقل تماماً عن `d:\Students`. لا تخلط بين كود المشروعين ولا ترفع ملفات هذا المشروع إلى مستودع السنتر.
- عند تعديل هذا المشروع، احرص على استخدام Vanilla HTML/JS/CSS بدون أطر عمل خارجية معقدة.
- الالتزام بنظام التصميم الداكن/الفاتح (Dark/Light Mode) بدون استخدام أي إيموجي (Emojis).
- أي اتصال بـ Supabase يتم عبر المفتاح العام (Anon Key) مباشرة لتحديث حقل `config.subscription`.
